# Daily Task

A simple and effective daily task manager built with HTML, CSS, and vanilla JavaScript.

## Features

- **Add Tasks:** Quickly add new tasks to your daily list.
- **Complete Tasks:** Mark tasks as complete with a single click.
- **Delete Tasks:** Remove tasks individually.
- **Clear All:** Clear the entire task list.
- **Local Storage:** Your tasks are automatically saved in your browser's local storage, so they persist between sessions.

## Tech Stack

- **HTML:** The structure of the application.
- **CSS:** Styling for the application.
- **Vanilla JavaScript:** The application logic and interactivity.

## Getting Started

1.  Clone the repository or download the files.
2.  Open `index.html` in any modern web browser.
3.  Type a task in the input field and press `Enter` or click the "Add" button.
4.  Click on a task to toggle its completed status.
5.  Click the `X` button to delete a task.
6.  Click the "Clear All" button to remove all tasks.
